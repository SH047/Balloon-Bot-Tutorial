## About the project

Balloon Bot uses an ESP32, an L298N motor driver, and a Bluetooth gamepad with Bluepad32. The project has single-stick arcade and two-stick tank control modes.

This repository shares the two recordings and this README. The videos are preserved without recompression; their SHA-256 checksums match the original local files. GitHub replaced spaces in the uploaded filenames with dots.
